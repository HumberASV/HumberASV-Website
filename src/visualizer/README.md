# Visualizer

This visualizer visualizes data from either a simulated data or telemetry from our ASV.

It has various element folders, including:

* `\controls` - controls for the visualizer, such as sliders and buttons
* `\entity` - moving entities in the visualizer, such as the ASV and obstacles
* `\hud` - heads up display, showing information about the ASV and the environment
* `\scenes` - different scenes for the visualizer, such as the map and physics
* `\svg` - svg elements for the visualizer, such as the map and obstacles

> [!NOTE]
> These elements are all contained in the `src/visualizer` directory. The visualizer is built using React and TypeScript, and uses the Material UI library for its components.
